# higuma — 北海道ヒグマ出没情報の時空間分析

北海道ヒグマの出没情報から、ヒグマの相対的な出没・空間利用パターンと人間側の観測・通報努力をどこまで分離できるか、
分離した上で秋季食物資源の豊凶・気象と対応づけられるかを検証するプロジェクト。

詳細な研究計画・フェーズ定義は [PROJECT_SPEC.md](PROJECT_SPEC.md) を参照。
